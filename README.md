# Pong Game in C (DTEK-V)
This project was developed as part of a programming assignment at KTH.  
It implements a simple Pong game in C for the DTEK-V embedded board.  
All gameplay logic shown here was implemented together with a course partner, and course-provided files have been excluded.

## How to Run
To run the program on actual hardware:
1. Build the project using the DTEK-V RISC-V toolchain.
2. Load the compiled file onto the DTEK-V board.
3. Run the program using the appropriate toolchain for the DTEK-V board.

## Notes
- This repository excludes all course-provided files.
